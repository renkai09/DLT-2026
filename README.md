# 基於擬全息投影技術之跨域推薦系統 (Cross-domain Recommendation System Based on Pseudo-Holographic Projection Technology)

本專案為 **2026 數位生活科技研討會 (DLT 2026)** 的投稿作品。

## 團隊成員
蘇家輝、吳晧安、鄭仁凱、余仲評、林猷樂
(國立高雄大學資訊工程系)

## 專案簡介
隨著人工智慧與物聯網 (AIoT) 的發展，智慧家居系統逐漸由單一功能導向整合式應用發展。然而，現有智慧助理大多局限於聲音或 2D 螢幕互動，缺乏真實感與情感陪伴。

本研究提出一套結合以下技術的**智慧互動平臺**：
- 跨媒體推薦技術 (Cross-media Recommendation)
- 全息投影技術 (Holographic Projection)
- 語音辨識與深度自然語言處理 (NLP)
- 智慧資料推薦與高度擬人化的 AI 對話系統

透過結合視覺、聽覺與智慧運算，將虛擬角色以三維 (3D) 形式呈現於現實空間中，為使用者打造一個具備情感連結之立體虛擬生活夥伴，有效提升互動真實性與沉浸感。

## 系統特色
- **技術性**：整合了跨媒體服務推薦技術（導入重啟隨機遊走 RWR 演算法）、全息投影技術（基於佩珀爾幻象 Pepper's Ghost 光學原理）、語音辨識及自然語言理解模型。
- **創新性**：全息互動助理市場尚屬高度未開發的藍海領域，具備先發優勢與技術壁壘。
- **應用性**：場域極具擴展性與彈性，可快速部署至娛樂、零售、教育以及智慧醫療等多元領域。
